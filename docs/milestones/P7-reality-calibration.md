# P7 — Reality Calibration

## Inputs

真实匿名 Historical Snapshot、Planner review context 和目标部署环境。

## Outcome

执行 Historical Replay、Synthetic Comparison、FactoryProfile Calibration、Solver Benchmark、Planner Baseline Comparison 和 Production Capacity Decision。

## Reality Gap

比较真实/合成 routing depth、candidate density、calendar fragmentation、bottleneck 和 solver runtime 等，持续改进 Simulation。

## Gate

形成 Reality Gap Report、生产性能边界并推动关键 PROD_OPEN 关闭。P7 不得成为第一次性能测试，历史数据缺失时不能宣称生产就绪。
