PlantNexus 精密机加工 / CNC 排产演示（Windows x64）
=====================================================

这是仅含合成数据的 Simulation Demo，不是生产系统，不得接入公网或真实生产数据。

快速开始
--------
1. 把整个解压目录放在当前用户有写权限的位置。
2. 双击“启动演示.cmd”。浏览器默认打开 http://127.0.0.1:4174/demo/ 。
3. 首次进入后点击“初始化演示工厂”，即可生成固定的 132 单 / 610 工序 / 24 设备场景。
4. 演示结束后双击“停止演示.cmd”。

修改端口与局域网访问
--------------------
1. 先运行“停止演示.cmd”。
2. 右键“配置演示.ps1”，选择“使用 PowerShell 运行”；也可用文本编辑器修改 config\demo-settings.json。
3. access_port 是前端和 API 共用的唯一端口。
4. 仅本机模式：lan_mode=false，listen_host=127.0.0.1，allowed_networks=[]。
5. 可信局域网模式：lan_mode=true，listen_host=0.0.0.0，并在 allowed_networks 中仅列出演示终端实际使用的私有 CIDR。
6. 重新启动后，局域网终端访问 http://本机局域网IP:端口/demo/ 。

Windows 防火墙
--------------
程序不会自动修改防火墙。若局域网终端无法连接，请由现场管理员仅为所选 TCP 端口、专用网络配置入站规则；演示结束后可禁用或删除该规则。不要创建“任何端口/任何网络”的规则。

安全边界
--------
- 默认只接受本机连接。
- 局域网模式只接受配置中允许的 RFC1918 IPv4 或 ULA IPv6 socket peer；不信任 X-Forwarded-For 等代理头。
- HTTP 无加密，只能用于隔离、可信的演示局域网；不得直接暴露到互联网。
- 所有数据均为固定 seed 的合成数据；新重排版本保持 DRAFT，不会自动发布。

排障
----
- “查看状态.cmd”显示运行状态、端口和本机地址。
- 启动失败日志位于 runtime\logs\。
- 端口占用时先停止旧实例，或修改 access_port。
- 启动/停止会核对 PID 与进程创建标记，不会终止身份不匹配的未知进程。
