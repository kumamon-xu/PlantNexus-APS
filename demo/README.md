# PlantNexus APS CNC 排产演示

PlantNexus APS CNC 排产演示是一套面向精密机械零部件与 CNC 机加工车间的高级计划排程（APS）展示应用。它使用固定的合成工厂数据，完整演示从订单初始化、自动排产到加急插单和动态重排的业务流程。

界面默认使用中文，适合产品演示、方案交流、售前展示与内部培训。

## 功能概览

- 单工厂、3 个车间和多类加工设备的统一排程；
- 每个订单包含 3～6 道有先后关系的加工工序；
- 每道工序支持多台候选设备；
- 综合设备日历、维护停机、物料到齐时间和订单交期；
- 区分普通、重点、加急订单及不同排产优先级；
- 保留已完成、正在加工、冻结窗口和锁定工序；
- 展示订单、设备甘特图、资源负荷、交付表现和校验结果；
- 支持加急订单插入、自动重排、版本比较和变更报告；
- 明确区分求解器的 `OPTIMAL` 与经 Validator 验证的 `FEASIBLE` 结果。

## 演示数据

默认演示场景采用固定种子，可随时重置并重复演示：

| 项目 | 默认规模 |
|---|---:|
| 工厂 | 1 个 |
| 车间 | 3 个 |
| 设备 | 24 台 |

## Windows 快速开始

系统要求：Windows 10/11 x64，以及可用的现代浏览器。

1. 获取 `PlantNexus-CNC-Demo-Windows-x64-0.2.3.zip`。
2. 校验随包提供的 `.zip.sha256` 文件。
3. 完整解压 ZIP 到当前用户具有写权限的目录。
4. 需要远端查看时，先运行 `配置演示.ps1`，设置端口及允许访问的网段。
5. 双击 `启动演示.cmd`。它只启动服务，不会自动打开本机浏览器；看到成功提示后可按任意键关闭命令窗口，服务会继续运行。
6. 双击 `查看状态.cmd` 确认服务就绪，在远端终端手工打开 `http://演示机可达IP:端口/demo/`。
7. 演示结束后双击 `停止演示.cmd`。

独立发布包已包含前端、服务端、数据库迁移、演示数据、排产求解器和校验器，运行时无需安装 Python、Node.js、npm 或 uv。

## 推荐演示流程

1. 点击“初始化演示工厂”，生成固定的订单、工序、设备和日历数据。
2. 点击“自动排产”，等待系统生成初始排程版本。
3. 查看订单交期、甘特图、设备负荷和 Validator 校验结果。
4. 将初始方案设为仿真基线。
5. 点击“插入加急订单”，选择产品路线并填写数量、交期和优先级。
6. 等待系统保留既有执行事实并完成自动重排。
7. 比较插单前后的工序移动、设备变化、开始时间偏移和交付指标。

动态重排结果以 `DRAFT` 形式展示，不会自动替换已发布的仿真基线。

## 修改访问端口

前端和 API 使用同一个访问端口。修改前请先停止演示，然后运行 `配置演示.ps1`，或编辑：

```text
config\demo-settings.json
```

仅本机访问示例：

```json
{
  "access_port": 18080,
  "allowed_networks": [],
  "lan_mode": false,
  "listen_host": "127.0.0.1",
  "open_browser": false,
  "settings_version": "cnc-demo-windows-settings.v1"
}
```

保存配置并重新启动后，通过 `http://127.0.0.1:18080/demo/` 访问。

## 局域网访问

需要让同一可信局域网中的其他终端访问时，可在 `配置演示.ps1` 中启用局域网模式。推荐只允许实际演示终端所在的最小私有网段。

```json
{
  "access_port": 18080,
  "allowed_networks": [
    "192.168.20.0/24"
  ],
  "lan_mode": true,
  "listen_host": "0.0.0.0",
  "open_browser": false,
  "settings_version": "cnc-demo-windows-settings.v1"
}
```

重新启动后不会自动打开浏览器，其他终端手工访问：

```text
http://演示机局域网IP:18080/demo/
```

程序不会自动修改 Windows 防火墙。若需要跨终端访问，请由管理员仅为所选 TCP 端口和可信专用网络配置入站规则。

## 公网访问（显式启用）

`0.2.3` 起可在 `配置演示.ps1` 中选择“公网开放”，对应 `allowed_networks=["0.0.0.0/0"]`。该设置仅放开应用的 IPv4 来源限制；仍需由管理员配置 Windows 防火墙、云安全组以及路由器/NAT 端口映射。公网模式没有 TLS，也不是生产认证方案，仅应在明确受控的临时演示窗口使用，结束后应立即恢复为指定网段或仅本机模式。

## 常见问题

### 端口被占用

先运行 `停止演示.cmd`。如果端口仍不可用，请通过 `配置演示.ps1` 更换端口后重新启动。

### 局域网终端无法访问

依次检查演示服务状态、局域网 IP、允许网段、Windows 网络类型和防火墙入站规则。`查看状态.cmd` 可显示当前运行地址和端口。

### 需要恢复演示数据

使用页面中的“重置演示”重新生成固定场景，不要直接修改 `runtime/` 中的数据库文件。

### 启动失败

查看 `runtime\logs\` 中的最新日志。请确保发布包已完整解压，所在目录可写，并且没有只复制可执行文件而遗漏 `_internal/`。

### 启动后没有浏览器窗口

这是预期行为。`0.2.1` 起启动入口固定为纯服务模式；`0.2.2` 修复了 Windows `cmd.exe` 对非 CRLF 启动脚本的兼容问题，同时兼容 Windows PowerShell 5.1 的中文脚本编码；`0.2.3` 增加了显式公网网段选项。请运行 `查看状态.cmd` 确认端口，再从远端终端手工访问。配置中的 `open_browser` 必须保持 `false`。

## 使用边界

- 本项目是 Simulation 演示，不是生产系统；
- 只能使用包内提供的合成数据；
- 远端访问使用未加密 HTTP；公网模式仅适用于经明确授权、受边界保护的临时演示；
- 公网开放时必须另行承担 TLS、访问控制、路由/NAT 和暴露面的安全风险；
- 不提供生产身份、TLS、Windows Service、自动更新或真实数据接入能力。
