PlantNexus 精密机加工 / CNC 排产演示（Windows x64）
=====================================================

这是仅含合成数据的 Simulation Demo，不是生产系统，不得接入真实生产数据。

快速开始
--------
1. 把整个解压目录放在当前用户有写权限的位置。
2. 需要远端查看时，先运行“配置演示.ps1”，选择访问模式、端口和允许网段。
3. 双击“启动演示.cmd”只启动后台服务，不会自动打开浏览器。
   看到成功提示后可按任意键关闭命令窗口，后台服务会继续运行。
4. 双击“查看状态.cmd”确认服务就绪；远端终端手工打开 http://演示机可达IP:端口/demo/ 。
5. 首次进入后点击“初始化演示工厂”，即可生成固定的 132 单 / 610 工序 / 24 设备场景。
6. 演示结束后双击“停止演示.cmd”。

修改端口与远端访问
------------------
1. 先运行“停止演示.cmd”。
2. 右键“配置演示.ps1”，选择“使用 PowerShell 运行”；也可用文本编辑器修改 config\demo-settings.json。
3. access_port 是前端和 API 共用的唯一端口。
4. 仅本机模式：lan_mode=false，listen_host=127.0.0.1，allowed_networks=[]。
5. 指定网段模式：lan_mode=true，listen_host=0.0.0.0，并在 allowed_networks 中列出允许访问的 CIDR。
6. 公网开放模式：allowed_networks=["0.0.0.0/0"]，允许任意 IPv4 来源；只应在明确受控的临时演示窗口使用。
7. 重新启动后，远端终端访问 http://本机可达IP:端口/demo/ 。
8. open_browser 固定为 false；改为 true 会被拒绝，服务不会调用本机浏览器。

Windows 防火墙
--------------
程序不会自动修改防火墙。远端访问需由管理员为所选 TCP 端口配置 Windows 防火墙；互联网访问还需配置云安全组或路由器/NAT 端口映射。演示结束后应禁用或删除公网规则。

安全边界
--------
- 默认只接受本机连接。
- 网络访问模式只接受配置中允许的 socket peer CIDR；不信任 X-Forwarded-For 等代理头。
- HTTP 无加密，公网开放也不提供生产级认证或 TLS；只可用于经明确授权的临时演示。
- 所有数据均为固定 seed 的合成数据；新重排版本保持 DRAFT，不会自动发布。

排障
----
- “查看状态.cmd”显示运行状态、端口和本机地址。
- 启动失败日志位于 runtime\logs\。
- 若双击启动窗口直接消失且服务未运行，请确认使用 0.2.2 或更高版本；该版本已将所有 CMD 入口固定为 Windows CRLF 格式，并兼容 Windows PowerShell 5.1 的中文脚本编码。0.2.3 起支持显式公网网段。
- 端口占用时先停止旧实例，或修改 access_port。
- 启动/停止会核对 PID 与进程创建标记，不会终止身份不匹配的未知进程。
